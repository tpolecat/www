# Cleaning Tools and Supplies

- [**Soft Paint Brush**]. A soft-bristled paintbrush is good for loosening dust from old PCBs and for sweeping off my benchtop.
- [**DeoxIT Contact Cleaner**]. I really like this stuff for cleaning up crusty switches, potentiometers, sockets, etc., on old things I'm trying to repair. Seems to be made of magic.
- [**99% Isopropyl Alcohol**]. I keep little spray and squirt bottles of this on my bench and use it for cleaning up flux, loosening stickers, spot cleaning, etc. I started with rubbing alcohol, but the 99% stuff evaporates much more quickly. I also keep a spray bottle and microfiber cloth next to my 3D printer so I can clean the build plate after every print.
- [**Acetone**]. Acetone is a strong solvent that will damage a lot of materials, so I don't use it much. But it's great for deep-cleaning my 3D printer's build plate and for getting superglue off my fingers.
- [**Simple Green**]. This seems to be the cleaner of choice for electronics restoration, so I use it on keycaps and cases and grimy things and it works fine. I don't like the smell.
- [**Air Canister**]. It's fun to blow dust out of stuff but I need to remember to do it outside.
- [**Chemtronics Flux Remover**](https://www.amazon.com/dp/B00DK2AY1U). I kind of want to get an [**ultrasonic cleaner**] to clean off PCBs, but for now I'm using this flux cleaner when I need to clean an entire board and it works well, but it smells like poison so definitely use outside. Probably kills grass.
