# Soldering Tools and Supplies

I do a lot of soldering (the Altair 8800c alone was more than 2500 solder joints) and I'm really happy with this relatively inexpensive setup.

## Tools

- [**Geeboon**]
- [**Yihua 959D Hot Air Station**](https://www.amazon.com/YIHUA-959D-Digital-Efficiency-212°F-932°F-Iron-burn/dp/B08BK3M6YW). I got this for SMD soldering when I was making [**Numitron clocks**] and it works fine. I also use it for heat-shrink tubing and loosening up stiff PVC cables.
- [**xxx Hot Plate**]()
- Magnet Board Thing.
- [**Engineer Solder Sucker**](https://www.amazon.com/gp/product/B002MJMXD4). All metal except for the bendy silicone [**tip**](https://www.amazon.com/gp/product/B003K0B3HG). I like the stubby size because I have small hands. I found that solder suckers create enough vacuum pressure to lift pads on old boards, so I try to use wick when I can.

## Supplies

- [**Kester 24-6337-8807 Solder**](https://www.amazon.com/gp/product/B004L4VHJE). This is 0.5mm 63/37 leaded solder wire and I really like it for PCB work. I initially got a spool of thicker (0.8mm) [**24-6337-8800**](https://www.amazon.com/gp/product/B00068IJOU) wire but it didn't work well with the tip I normally use, which sucks because it's an expensive spool of solder. I still use it when I switch to the big tip, which isn't very often.
- [**Chip Quik SMD291AX Solder Paste**](https://www.amazon.com/gp/product/B0186IM0P0). I use this for SMD soldering and it works well. Very easy to deal with.
- [**Chip Quik Tack Flux**](https://www.amazon.com/gp/product/B00CM2A97S). Good sticky flux. Solves all problems.
- [**Chip Quik Liquid Flux**](https://www.amazon.com/dp/B095KXMGT5). Good liquid flux. Solves all problems.
- [**MG Chemicals Super Wick**](https://www.amazon.com/gp/product/B00424MWHO). This stuff is magic. It's nothing at all like cheap braid. It works amazingly well.
- [**Weller Tip Tinner**](https://www.amazon.com/gp/product/B002V7QDZQ). Sometimes a tip gets into a state where the surface immediately oxidizes after cleaning, so solder won't stick to it. This stuff smells like Satan when it burns but it fixes the problem.
- heat sink compound
- paste flux
- solder reel
- Kapton Tape

## Retired Tools

- [**Hakko FX-888 Soldering Station**](https://www.amazon.com/Hakko-FX888D-23BY-Digital-Soldering-Station/dp/B00ANZRT4M). This was the first "expensive" tool I bought, and I was really worried that it wouldn't work out because I had never really soldered before. It worked out well and if you can get one for free, go for it. But if you're buying one now I would go for a JBC-style iron like the Geeboon above.

## Loser Soldering Tools and Supplies

Here are come soldering tools and supplies that didn't work out.

- [**Helping Hands**](https://www.amazon.com/gp/product/B000P42O3C). Everybody sells these in their soldering kits, so I got one thinking it would be good. It was not. Literally nothing about it is good.
- blue tack
- cheap solder
- [**Cheap Solder Suckers**](https://www.amazon.com/gp/product/B081ZRY3T3). The cheap blue solder suckers clog easily and the tip is not very heat-resistant. Also hard for me to use one-handed.
- [**Cheap Wick**](https://www.amazon.com/gp/product/B081ZRY3T3). Cheap braid doesn't absorb solder very well so it's frustrating to use and exposes the board to more heat.
- [**Yihua 30W 929D-V Desoldering Iron**](). This seemed worth a try but it doesn't work well. Maybe I'm doing it wrong.
- **Scotch Tape**. Before I discovered Kapton tape I tried holding parts in place with Scotch tape, with predictable results.
