# Measuring and Inspection Tools

## Measuring Tools

- Rulers (plus good ruler)
- Scale Lupe
- Caliper
- Tape Measure

## Inspection Tools

- **Binocular Microscope**. See the [dedicated page] on this.
- [**IR Camera**]()
- [**Drugstore Reading Glasses**](https://www.lowes.com/pd/Hillman-Retro-Black-3-0-Magnification-2-Pair-2-Soft-Cases/5001940057). I use 3.0 magnification reading glasses when I'm working at the bench. They work great for me. If I need more magnification I swing the microscope over.
- [**Mini LED Flashlight**](https://www.amazon.com/gp/product/B09DP33SC9). I got a 10-pack of these because flashlights seem to disappear around here. They're super useful for reading markings on parts and for finding things that roll under the table.
